# Decision log

Every decision taken after the frozen v1.0 specification (`spec/`), with its date: the owner's choices and the
gaps the spec left open. Binding for the code and the docs, which cite entries as "decision 9" or "L32".

Decisions are never deleted: when one is replaced, mark it superseded and add the new one. New entries take the next
L number and go at the end of the second table. Kept in the design workspace (`D:/design/hera-editing`) until the
design run closed on 2026-11-18; this file is the record from then on.
